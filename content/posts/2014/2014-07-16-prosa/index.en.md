For the last two months I've been working on a secret personal project:
building a "blog server" in the spirit of
[Medium](http://medium.com).

The fruit of that work is [Prosa](http://prosa.io), my own content
publishing platform, one that meets my needs.

This blog turns nine on August 1; from that date on it will be published
using Prosa. That day I will also publish the source code of this tool.
So stay tuned.

In the meantime, you can read some of the reasons why I decided to write
"Prosa" [over there](/en/blog/lnds/2014/07/16/reasons-for-prosa/).
