Three years ago now, when the google api came out, I wrote a program I
called TOOTD6, based on TOOT: Tool Of Objective Truth, a game that used
the google api to determine objective truth, based on the number of
times a term (or a phrase) shows up referenced in google.

The world wasn't ready for TOOTD6, but now I think it has a chance :)

For now it's Windows only, but as soon as I finish getting Ubuntu
properly installed, I promise to compile a version for the linux crowd.

It isn't open source, sorry, but anyone who wants to know how to build
it can write to me.

So you can download the 2005 version of TOOT, called LNDSTOOTD7,
[here](http://replay.waybackmachine.org/20060211180549/http://www.lnds.net/downloads/LndsTootD7.zip).
