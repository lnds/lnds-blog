Firefox uses a lot more memory than Internet Explorer. In my case IE takes about 25 MB when I start it pointed at this site, while Firefox takes about 37 MB, and that's nearly constant. I should say that both browsers have almost the same number of plugins on my machine; IE even has more toolbars and add-ons than Firefox.

But the worst part is that you can end up like Red Guy after two days of browsing with Firefox: look at this image of his memory usage. Firefox doesn't release memory. Let's hope it gets better with time, because I'm starting to lose my illusions.
