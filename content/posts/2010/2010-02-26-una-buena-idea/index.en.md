Philip Tellis, a Yahoo engineer, has proposed [a very
interesting idea](http://tech.bluesmoon.info/2010/02/missing-kids-on-your-404-page.html):
use [404 error](http://es.wikipedia.org/wiki/Error_404) pages
(the page-not-found error) for a worthy purpose: publishing information
about missing children.

It's actually easy to implement; the problem is where to get the
information. Tellis uses the API of the site
<http://www.missingkidsmap.com/> to implement this feature,
but that site shows information about missing children in the US, Canada and
Great Britain.

Where do we have that information available in Chile? I'd like to
implement this service, but I don't know where to get data on missing
children in Chile or Latin America. So if anyone knows where
to get it, I'd be grateful. I hope to implement
this idea on this site in the next few days, and to show how to do it.
