Today we published release 0.2.1.19 of akarru.
You can get it from [sourceforge](http://web.archive.org/web/20090426080926/http://sourceforge.net/project/showfiles.php?group_id=155783)

### Changes in this version

version 0.2.1.19

From now on, version numbering will work as follows:

X.x.M.D

Where X is the major version number and x the minor version number, always
incremental. M is the month and D the day the distribution was created.

This version includes several bug fixes.
Some new things:
- primitive trackback discovery
- the folksonomy now shows only the top 100 tags
- user statistics (stats.php)
- influence and popularity
- experimental meme promotion algorithm
- promote_queue script, runnable by the admin
- several DB changes to improve performance
