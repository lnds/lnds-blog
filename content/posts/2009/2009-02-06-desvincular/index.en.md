[According to the RAE](http://www.rae2.es/desvincular):

**desvincular** (to unlink).

**1.** tr. To annul a link, freeing what was bound by it, especially property.

In programming

When we have a data structure like the following:

```
class Link  
{  
    T data;  
    Link prior;  
    Link next;  
}
```
  
then unlinking would be the following:

```
void desvincular(Link link)  
{  
    link.prior = null;   
    link.next = null;  
}
```

In Chile

On the TV news, "desvincular" means something else. It's a euphemism for [dismissing](http://www.rae2.es/despedir), [terminating](http://www.rae2.es/cesar), [firing](http://www.rae2.es/echar), leaving someone without a job.  
  
Usage:

> Are you unemployed?   
>  
> No! How could you think that? I was unlinked.
>   

see also [euphemism ](http://www.rae2.es/eufemismo).
